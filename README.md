# Euclid Chart Designer

Web-based chart design tool for configurable, developer-ready bar charts.

## Commands

- `npm run dev` — start the editor
- `npm run build` — production build
- `npm test` — unit tests (pattern determinism, spec schema)

## Features (MVP)

- **Classic** — grouped/stacked Cartesian bar charts (Canvas)
- **Breakdown** — sectioned horizontal bars with in-bar labels
- **Hierarchy** — expandable tree rows with depth styling
- Preview data patterns + randomize (deterministic seed)
- Settings / Colors inspector, light/dark UI + chart presets
- JSON export/import with embedded data values
- Undo/redo (Ctrl+Z / Ctrl+Y), localStorage autosave
